-understood and solved an error related to DNS lookup. My public IP = device ip + ISP's modifications , so it keeps changing ( dynamic ). MongoAtlas has 2 way security , it also checks whether an authorized IP is requesting connection before it authenticates the credentials being provided to access DB. Even before this , to reach MongoAtlas i.e. to reach the cluster where IP is checked , first step is where DNS lookup is performed by the ISP/Router. My ISP denied/refused to perform that , node js uses standard DNS queries for finding a record's address but I was using a special query ( SRV records aka Service records ) which is usually blocked or not supported by most DNS providers.
